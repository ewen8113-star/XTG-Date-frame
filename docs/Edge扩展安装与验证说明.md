# 鑫通告数据导入助手：Windows Edge 安装与验证说明

## 一、准备文件

将 `鑫通告数据导入助手-Edge-v0.3.0.zip` 复制到同事的 Windows 电脑，解压到固定位置，例如：

```text
D:\XTG\xtg-edge-importer
```

解压后的文件夹内应当可以直接看到 `manifest.json`。安装后不要移动或删除该文件夹。

## 二、安装到 Edge

1. 打开 Microsoft Edge。
2. 在地址栏输入 `edge://extensions/` 并回车。
3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择刚才解压的 `xtg-edge-importer` 文件夹。
6. 确认扩展列表中出现“鑫通告数据导入助手”。
7. 点击 Edge 工具栏的扩展按钮，将“鑫通告数据导入助手”固定到工具栏。

本次内部验证不需要登录 Microsoft Edge 扩展商店，也不需要发布扩展。

如果已经安装旧版，请先在 `edge://extensions/` 删除旧版，再加载 v0.3.0。扩展卡片中的版本号必须显示为 `0.3.0`。

## 三、连接运营后台

1. 确认同事可以正常访问你的运营系统。
2. 复制同事浏览器地址栏中的系统地址，例如：

```text
http://192.168.1.20:5174
```

3. 在同一个 Edge 浏览器中登录鑫通告管理后台。
4. 打开鑫通告用户管理页。
5. 点击工具栏中的“鑫通告数据导入助手”。
6. 在“运营后台地址”中粘贴系统地址。
7. 点击“保存并测试”。
8. Edge 询问网站访问权限时选择“允许”。
9. 看到“连接成功，地址已保存”后继续。
10. 重新加载扩展版本后，请再次点击一次“保存并测试”，然后刷新运营后台页面，以启用系统按钮与扩展之间的连接。

v0.3.0 中，系统按钮会先把任务提交到运营后台，扩展会在最多约30秒内自动领取。验证时请保持 Edge 运行，不要立即重复点击按钮。

## 四、验证经纪人导入

1. 在鑫通告打开用户管理/经纪人列表页面。
2. 确认页面表格已经正常显示。
3. 点击扩展图标打开导入助手。
4. 确认“页面类型”显示为“经纪人列表”。
5. 点击“导入当前经纪人列表”。
6. 等待显示导入完成。
7. 回到运营后台刷新经纪人页面，核对人数和一至两名经纪人资料。

在运营后台点击“导入经纪人数据”时，页面可能先等待数秒至约30秒，这是扩展领取后台任务的正常时间。

## 五、验证通告导入

1. 在鑫通告进入一位经纪人的详情页。
2. 切换到该经纪人的通告列表。
3. 点击扩展图标打开导入助手。
4. 确认“页面类型”显示为“经纪人通告列表”。
5. 点击“导入当前经纪人的通告”。
6. 保持导入助手页面开启。扩展会在后台逐条读取通告详情。
7. 显示导入完成后，回到运营后台刷新该经纪人的通告页面。
8. 随机打开一条通告，核对标题、状态、报名人数、签约人数和详情内容。
9. 在通告审核页点击“导入签约者信息”，确认不再出现需要本机 Chrome 抓取包的提示。

## 六、验证时需要记录的信息

如果失败，请记录以下内容并截图：

- Edge 显示的完整错误提示。
- 当前打开的鑫通告页面地址。
- 导入的是经纪人还是通告。
- 运营后台地址。
- Edge 扩展管理页中是否显示错误。

查看扩展错误的方法：打开 `edge://extensions/`，找到本扩展，点击“错误”或“检查视图”。

## 七、常见问题

### 没有找到鑫通告页面

保持鑫通告页面打开，在导入助手中点击“重新识别”。如果仍然失败，刷新鑫通告页面后再试。

### 连接运营后台失败

确认填写的是同事平时访问运营系统的完整地址，并确认同事电脑仍然可以打开该地址。不要填写 `localhost`，除非运营后台确实运行在同事自己的电脑上。

### 页面能打开但没有识别到数据

确认鑫通告登录没有失效，且页面表格已经加载完成。刷新页面后重新导入。

### 扩展文件更新

用新文件覆盖原扩展文件夹，然后进入 `edge://extensions/`，点击扩展卡片上的“重新加载”，最后刷新鑫通告页面。

## 八、数据说明

- 扩展只在 `https://jarvis.tong-gao.com/*` 页面读取 DOM。
- 扩展只向使用者设置并授权的运营后台地址提交数据。
- 数据直接从同事的 Edge 发送到运营后台，不经过 AI 模型或扩展商店。
