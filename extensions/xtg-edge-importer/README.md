# 鑫通告数据导入助手（Edge / Chrome）v0.3.0

此扩展用于在同事自己的 Edge 或 Chrome 中读取已登录的鑫通告页面 DOM，并把经纪人及通告数据直接提交到运营后台。

v0.3.0 使用后台任务队列连接系统按钮与扩展。系统页面不再依赖直接识别本地扩展；扩展每30秒内自动领取一次导入任务。

## Windows Edge 安装

1. 将整个 `xtg-edge-importer` 文件夹复制到 Windows 电脑的固定位置，例如 `D:\XTG\xtg-edge-importer`。
2. 打开 Edge，在地址栏输入 `edge://extensions/`。
3. 打开页面左侧或右侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的 `xtg-edge-importer` 文件夹。
6. 在扩展列表中找到“鑫通告数据导入助手”，并将它固定到浏览器工具栏。

## 首次连接

1. 在同一 Edge 浏览器中登录鑫通告管理后台。
2. 打开鑫通告的用户管理页或某位经纪人的通告列表页。
3. 点击工具栏上的“鑫通告数据导入助手”。
4. 填写同事平时访问运营系统所使用的完整地址，例如 `http://192.168.1.20:5174`。
5. 点击“保存并测试”。Edge 出现网站访问授权时选择允许。
6. 页面显示“连接成功”后即可导入。
7. 刷新已打开的运营后台页面。之后可直接使用系统中的“导入经纪人数据”和“导入通告数据”按钮。
8. 通告审核页中的“导入签约者信息”也会由扩展读取当前通告详情和签约人员名单。

## 验证经纪人导入

1. 在鑫通告打开用户管理/经纪人列表页面。
2. 点击扩展图标，打开导入助手。
3. 确认识别类型为“经纪人列表”。
4. 点击“导入当前经纪人列表”。
5. 等待显示导入完成，再回到运营后台刷新经纪人页面核对数据。

也可以在运营后台直接点击“导入经纪人数据”。扩展会在后台打开鑫通告页面并完成读取。

## 验证通告导入

1. 在鑫通告进入一位经纪人的详情页，并切换到通告列表。
2. 点击扩展图标，打开导入助手。
3. 确认识别类型为“经纪人通告列表”。
4. 点击“导入当前经纪人的通告”。
5. 保持导入助手页面开启。扩展会在后台逐条打开通告详情，完成后自动关闭临时页面。
6. 回到运营后台刷新该经纪人的通告页面进行核对。

也可以在运营后台经纪人工作台直接点击“导入通告数据”。扩展会根据当前经纪人 ID 自动打开对应的鑫通告通告列表。

## 常见问题

- 显示“没有找到鑫通告页面”：确认鑫通告页面没有关闭，然后点击“重新识别”。
- 显示“连接失败”：检查运营后台地址是否与同事平时访问系统的地址完全一致，并确认系统服务正在运行。
- 页面已打开但没有数据：刷新鑫通告页面，确认登录没有失效，并确认当前页面的表格已经显示。
- 扩展更新后：打开 `edge://extensions/`，找到本扩展并点击“重新加载”，然后刷新鑫通告页面。
- 文件夹不能移动：本地加载的扩展依赖原文件夹，移动后需要在 Edge 中重新加载。

## 数据边界

- 扩展只读取 `https://jarvis.tong-gao.com/*` 页面。
- 扩展只向首次设置并授权的运营后台地址提交数据。
- 数据不会发送给 AI 模型或扩展商店。
- 当前版本用于内部验证，不需要发布到 Microsoft Edge 加载项商店。
